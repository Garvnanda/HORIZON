## Notes

- **t** is the window index the forecast is anchored at; it must be >= 20 (the model needs 20 windows of history). The sidebar exposes 3 presets per host; any integer in range works via the API (`/api/forecast?capture=<cap>&host=<ip>&t=<n>`).
- **scenario** = adhoc means no scripted narrative; the host is still fully forecastable, it just has no ground-truth attack label attached for the demo overlay.
- Demo scenarios with a story: infiltration (thursday/192.168.10.8), botnet (friday/192.168.10.15), benign control (monday/192.168.10.9).
- Generated from `GET /api/hosts` on the live backend. Re-run after a new training run to refresh.
